# OSR11 — Kinetic Energy Trends and Eddy Saturation in the Southern Ocean

[![DOI](https://img.shields.io/badge/doi-10.5281%2Fzenodo.21485764-blue)](https://doi.org/10.5281/zenodo.21485764) [![Version](https://img.shields.io/badge/version-v1.0.0-blue)](https://github.com/cmartisolana/OSR11_Kinetic_Energy_Southern_Ocean/releases/tag/v1.0.0)

Analysis of kinetic energy (KE), eddy kinetic energy (EKE), frontal positions,
wind stress, and Drake Passage transport in the Southern Ocean, based on
satellite altimetry. This repository contains all code needed to reproduce the
figures of the main article and the supplementary material.

## Input data

Daily L4 gridded altimetry from Copernicus Marine (CMEMS):

- Product: `SEALEVEL_GLO_PHY_L4_MY_008_047`
- Dataset: `cmems_obs-sl_glo_phy-ssh_my_allsat-l4-duacs-0.125deg_P1D`
  (and the two-satellite equivalent for the robustness check)

Download with the [copernicusmarine toolbox](https://help.marine.copernicus.eu/en/collections/4060068-copernicus-marine-toolbox)
and organise files as `<input_dir>/<YYYY>/<MM>/*.nc`. Point the preprocessing
script at that folder with `--input-dir` or the `ALTIMETRY_DIR` environment
variable.

Observed Drake Passage transport is auto-downloaded (git clone) from
[manuelogtzv/TrendsDrakePassageTransp](https://github.com/manuelogtzv/TrendsDrakePassageTransp)
by `scripts/extract_observed_drake_geostrophic_transport.py`.

## Workflow

Each script writes to `outputs/`; each notebook reads from `outputs/` and
writes publication figures to `figures/`.

### Step 1 — Preprocessing

```bash
python scripts/half_power_EKE.py --input-dir /path/to/altimetry
# → outputs/monthly_half-power_points/YYYY/MM.nc
```

Run notebook **00** to produce the sea-ice mask and preprocessing grids.

### Step 2 — Front detection

Run notebook **01** → `figures/manuscript/front_trends_detection_example.png`
(panels a–b of the *front_trends* article figure).

### Step 3 — Regional trend tables

```bash
python scripts/ke_trends_analysis.py
# → outputs/trends/region_timeseries.csv, energy_field_timeseries.csv, trends_*.csv
```

Run notebook **02**.

### Step 4 — 2D KE/EKE trend fields

```bash
python scripts/ke_eke_2d_trends.py
# → outputs/trends/ke_eke_2d_trends.nc
```

### Step 5 — Main article figures

| Notebook | Article figure | File(s) in `figures/manuscript/` |
|----------|----------------|----------------------------------|
| **03a** | KE_EKE_trends | `KE_EKE_trends.png` |
| **01** + **03b** | front_trends | `front_trends_detection_example.png` (a–b) + `front_trends_timeseries_bars.png` (c–f) |
| **05** | — (computes wind stress CSVs required by 06/07) | |
| **06** | — (computes transport CSVs required by 07) | |
| **07** | drake_passage | `drake_passage_ke_eke.png` and `drake_passage_eke.png` (toggle `INCLUDE_KE` in the publication-figure cell) |

Observed Drake transport CSVs (needed by 06/07):

```bash
python scripts/extract_observed_drake_geostrophic_transport.py
# → outputs/trends/drake_passage_*_observations.csv
```

### Step 6 — Supplementary figures

| Notebook | Article figure | Prerequisite script | File(s) in `figures/supplementary/` |
|----------|----------------|---------------------|--------------------------------------|
| **s01** | KE_EKE_trends_since2010 | `python scripts/ke_eke_2d_trends_since2010.py` | `KE_EKE_trends_since2010_maps.png` + `_bars.png` |
| **s02** | KE_EKE_trends_since2016 | `python scripts/ke_eke_2d_trends_since2016.py` | `KE_EKE_trends_since2016_maps.png` + `_bars.png` |

The final article figures are composites of these panels (maps on top,
bars/timeseries below).

## Trend methodology

- **Slope estimator:** Theil–Sen
- **Significance:** Modified Mann–Kendall with Yue–Wang autocorrelation correction (p < 0.05)
- **2D maps:** full trend field shown in colour; significant pixels marked with stipple dots
